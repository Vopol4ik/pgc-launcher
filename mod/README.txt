pgcclient mod — recovery note
=============================

The original Java sources for this mod were lost and are not present in the
recovered launcher repository or the globalwar-updates manifest repo.

The compiled artifact pgcclient.jar was recovered by extracting it from the
official modpack archive:

  launcher/resources/content.7z  (entry: pgcclient.jar)

This copy is placed under mod/build/libs/ for local Gradle-style layout and
mirrored under svo-build/mods/ for the client mod folder.

Do not treat this tree as authoritative source code; only the JAR is available.
